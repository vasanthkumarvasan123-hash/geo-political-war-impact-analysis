# Geo-Political War Impact Analysis

## Project Overview

This project analyzes the impact of geopolitical conflicts on military activities, casualties, commodity prices, and economic indicators.

The analysis focuses on attack patterns, casualties, missile and drone launches, oil price fluctuations, gold price movements, and stock market behavior during conflict periods.

## What I Did

- Processed and analyzed 10,000+ geopolitical conflict records
- Created new metrics such as Total Attacks and Total Casualties
- Performed data cleaning and preprocessing using Python
- Conducted Exploratory Data Analysis (EDA)
- Wrote SQL queries for military and economic analysis
- Built interactive Power BI dashboards
- Developed Tableau visualizations for conflict monitoring

## Key Findings

- Total Attacks exceeded 200K during the study period
- Total Casualties crossed 237K
- Missile launches reached 120K+
- Drone attacks exceeded 80K
- Oil prices increased during periods of intense conflict
- Gold prices showed safe-haven behavior during geopolitical instability
- Certain regions recorded significantly higher casualty rates than others
